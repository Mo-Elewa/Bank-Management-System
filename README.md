# Bank Management Systm
## Descrition
A simple Bank Management System developed using python.
This project allows usersto manage bank accounts,perfor transactions,
 and store date using text files.

## Features
  Add New Account
  Autmatic Account Number Generation
  Show All Accounts
  Search Account
  Deposit Money
  Withdraw Money
  Transefer Money Between Accounts
  Update Account Transformation
  Delete Account with Confirmation
  Check Account Balance
  Transactio History
  Bank Statistics
  Save Data to File
  Load Data Automatically  
  Admin Login
